# App vehicle assets

Use the WebP assets in the vehicle chooser, with PNG fallbacks. Each canvas is 1040 × 720. Preserve its aspect ratio and use contain sizing. Keep the image background white.

The dimension text should be shown in the expanded selected-vehicle panel, ideally at least 320 logical pixels wide. Use the vehicle name for the collapsed row. The demo expands all options for review.

vehicles.json provides filenames, canvas sizes and accessible labels. The selection controls are local preview behavior. Connect the selected vehicle ID to your booking flow.

Parcel dimensions are illustrative values, not measured vehicle capacity. Replace them with fleet-verified figures before using them as booking limits.
